To-Do List Manager

A To-Do List Manager is a Python command-line application used to create, manage, and organize daily tasks. Users can add, update, delete, and mark tasks as completed easily.

Features

Add new tasks

View task list

Update tasks

Delete tasks

Mark tasks as completed

User-friendly menu system


Technologies Used

Python

Command Line Interface (CLI)


How to Run

1. Install Python


2. Save the file as todolist.py


3. Open terminal or command prompt


4. Run the program:



python todolist.py

Learning Outcomes

Python lists and functions

Loops and conditional statements

File handling basics

User input management
